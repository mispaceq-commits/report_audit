# Website Audit Report — 48 Digital

A4-format mockup pages for the **Website Audit** product. Built as plain HTML +
Tailwind CSS. Each page renders to PDF and high-DPI PNG via headless Chromium,
so the output can be opened directly in Illustrator (PDFs stay vector and
editable) and dropped onto product pages as images.

## Tech stack

- **HTML + Tailwind CSS** — one HTML file per A4 page in `src/pages/`. Page
  dimensions are set in millimetres so PDF export is pixel-accurate.
- **Puppeteer (puppeteer-core)** — drives a headless Chromium that's already
  on the machine to render each page to PDF + PNG. No extra Chromium download.
- **Google Fonts** — Montserrat (headings) and Inter (body), both loaded at
  build/export time via `@import` in `src/styles.css`.

## Project layout

```
src/
  pages/            One HTML file per A4 page (page-01.html, page-02.html, …)
  assets/icons/     SVG icons (gradient/isometric style) from the brand kit
  styles.css        Tailwind entry + base + component layers
  styles.build.css  Generated by `npm run build:css` (gitignored)
scripts/
  export.js         Headless Chromium → PDF + PNG for each page
dist/               Exported PDFs and PNGs
tailwind.config.js  Brand colours, fonts, design tokens
```

## Design rules

- **Heading colour:** `#1F3C88` (brand blue), Montserrat 700–900.
- **Body colour:** `#111111` (near-black), Inter 400–600.
- **Accent colour:** `#F58B24` (brand orange) — used **sparingly**. Page 1
  uses orange in two spots only: the divider under the main title and a tiny
  underline on the `24 Recommendations` card. No orange backgrounds, no orange
  headings.
- **Typography scale** is consistent across pages: section badges (~9.5 pt
  uppercase tracked), body (9–10 pt), headline numbers (40–48 pt), title
  (~56 pt). See `tailwind.config.js` and inline `style="font-size: …pt;"`.
- **Page size:** A4 portrait, 210 × 297 mm. Use `mm` units to keep layout
  consistent between browser preview and exported PDF.

## Quick start

```bash
npm install
npm run build:css        # builds src/styles.build.css from Tailwind
npm run serve            # http://localhost:8080/pages/page-01.html (live preview)
npm run export           # renders all src/pages/*.html to dist/*.pdf + dist/*.png
```

`npm run export` writes one `.pdf` and one `.png` per HTML page into `dist/`.
The PNGs are 3× DPI (≈ 2380 × 3370 px) so they're crisp when scaled. The PDFs
are vector — open them in Illustrator and the text, shapes, and SVG icons
stay editable.

## Adding a new page

1. Copy `src/pages/page-01.html` to `page-NN.html`.
2. Update the content. Keep the same shell (header, footer, page-a4
   container) for typographic and margin consistency.
3. Re-run `npm run build:css && npm run export`.

## Data source

Numbers and recommendations on page 1 come from the customer's real audit PDF
(`48 Hour Audit — BlinderLaw.com, May 6 2026`), specifically the
**Website Audit** sections — Site Health Overview, Top 3 Suggestions for
48-Hour Growth. Performance / SEO sections from the monthly performance
report are intentionally **not** used on this mockup.

## Output for Illustrator

- Open `dist/page-01.pdf` in Illustrator: each element is a separate object,
  text is still editable, icons stay as vector groups.
- If you'd rather start from a raster: use `dist/page-01.png` (3× A4) and
  place it on the artboard.
